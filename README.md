# CampusSmart — Smart College Management System

A beginner-friendly full-stack Project-Based Learning (PBL) demo for managing basic college information. It uses HTML, CSS, and JavaScript for the frontend, Node.js and Express for the backend, and a local JSON file for storage.

> **Important:** This is a college demonstration project, not a production-ready student information system. It has a role selector for demonstrating the student and faculty/admin views, but it does not implement real login, authentication, or authorization. Do not store real or sensitive student information in it.

## Features

### Student view
- Student profile snapshot
- Attendance percentage and marks
- Sample course timetable
- Campus notices

### Faculty / Admin demo view
- View all student records
- Add a student
- Update a student's attendance and marks
- Publish notices

### Technical features
- REST API built with Express
- JSON file persistence in `backend/data/db.json`
- Input validation and useful error messages
- Responsive layout for desktop and mobile
- No separate database server required

## Requirements

- Node.js 18 or later
- npm (included with Node.js)
- A web browser
- Git, if you want to publish the project to GitHub

## Run on Windows

1. Install the LTS version of Node.js from the official website: https://nodejs.org/
2. Open the project folder in Visual Studio Code, or open Command Prompt in the project folder.
3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the server:

   ```bash
   npm start
   ```

5. Open http://localhost:3000 in your browser.

The same Express server serves both the frontend and API. You do not need a second terminal or a separate frontend development server.

## Demo instructions

1. Choose **Student** from the “View as” menu to see the student-facing overview.
2. Choose **Faculty / Admin** to reveal management controls.
3. Open **Student records** and click **+ Add student** to create a record.
4. Use the **Attendance** and **Marks** buttons to update values.
5. Open **Campus notices**, publish a notice, and check that it appears on the dashboard.
6. Stop and restart the server; data should remain because it is stored in `backend/data/db.json`.

The initial records are sample data. Change or replace them in `backend/data/db.json` if needed.

## API endpoints

| Method | Endpoint | Purpose |
|---|---|---|
| GET | `/api/health` | Check that the API is running |
| GET | `/api/dashboard` | Dashboard summary, students, notices, timetable |
| GET | `/api/students` | List students |
| POST | `/api/students` | Add a student |
| PATCH | `/api/students/:id/attendance` | Update attendance |
| PATCH | `/api/students/:id/marks` | Update marks |
| GET | `/api/notices` | List notices |
| POST | `/api/notices` | Publish a notice |
| GET | `/api/schedule` | Get the timetable |

Example request body for `POST /api/students`:

```json
{
  "name": "Example Student",
  "email": "example@college.edu",
  "course": "B.Tech CSE",
  "year": "2nd Year"
}
```

Create a new **empty** repository on GitHub. Do not add a README or license there if you already have this README locally. Then, from this project folder, run:

```bash
git init
git add .
git commit -m "Build Smart College Management System"
git branch -M main
git remote add origin https://github.com/YOUR-USERNAME/smart-college-management-system.git
git push -u origin main
```

Replace `YOUR-USERNAME` with your GitHub username. If GitHub asks you to sign in, complete its browser authentication flow.

## Notes about deployment

`vercel.json` is included as a starting point for Vercel configuration. This demo writes to a local JSON file, which is suitable for local demonstration but is **not durable storage for serverless hosting**. On a serverless platform, local file changes may be lost and filesystem writes may not persist between invocations. For a reliable hosted version, use a managed database and add real authentication/authorization before deploying student data.

## Troubleshooting

- **`npm` is not recognized:** Install Node.js LTS, then close and reopen Command Prompt or VS Code.
- **Port 3000 is already in use:** In Command Prompt, run `set PORT=3001` and then `npm start`; open http://localhost:3001.
- **The page cannot reach the API:** Confirm that the terminal still shows the server running and that you opened the URL served by Express.
- **A record does not save:** Check that `backend/data/db.json` exists and is valid JSON. Do not delete the outer braces or commas between entries.
- **`package-lock.json` is missing:** Run `npm install`; npm creates it automatically.
